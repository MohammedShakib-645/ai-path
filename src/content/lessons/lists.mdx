## What you'll learn

A **list** is Python's ordered, changeable collection — your everyday container. Indexing, slicing and a handful of methods cover 90% of real usage.

```python
scores = [72, 88, 91, 65]

scores[0]        # → 72        (first item — counting starts at 0)
scores[-1]       # → 65        (last item)
scores[1:3]      # → [88, 91]  (slice: start inclusive, stop exclusive)
scores.append(99)               # add to the end
popped = scores.pop()           # remove & return the last item
```

> 💡 **Key insight:** `list[start:stop]` **never includes the stop index** and returns a *copy*. Slices can't reach the original list — mutate with methods (`append`, `sort`), read with slices.

## Why it matters for AI

Datasets arrive as lists of rows, tokens are lists of IDs, predictions are lists of labels. Ranking top-k results, batching data, collecting metric history — all list work. Later, NumPy arrays take over the heavy math, but the shape of the thinking stays the same.

## The methods you'll actually use

```python
nums = [3, 1, 2]
nums.sort()              # sorts in place → [1, 2, 3]
nums.reverse()           # in place → [3, 2, 1]
len(nums)                # → 3
nums.count(2)            # → 1
nums + [9, 8]            # concatenation → new list
3 in nums                # → membership check
```

| Operation | Result | Copy? |
| --- | --- | --- |
| `lst[1]` | one item | value |
| `lst[1:]` | new list | yes |
| `lst.append(x)` | mutates `lst` | no |
| `lst2 = lst` | second label, **same list** | no! |

## Copying — the trap that bites everyone

```python
a = [1, 2, 3]
b = a                # ⚠️ NOT a copy — b points at the SAME list
b.append(4)
print(a)             # → [1, 2, 3, 4]  (a changed too!)

c = a.copy()         # ✅ independent copy
# or: d = list(a), or the slice e = a[:]
```

> ⚠️ Nested lists need a **deep copy** (`import copy; copy.deepcopy`) — a shallow copy still shares the inner lists.

## Common mistakes

> ⚠️ Off-by-one from 0-based indexing (`scores[3]` is the *fourth* item), reading past the end (`IndexError`), and believing `b = a` cloned anything.

## Quick recap

- Ordered, 0-based, negative indices count from the end, slices exclude the stop.
- Mutating methods change the list; `+`, slices and `copy()` make new ones.
- `b = a` is a second label, not a clone — use `.copy()`.
